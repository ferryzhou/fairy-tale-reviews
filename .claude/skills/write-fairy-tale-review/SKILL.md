# Skill: 基督信仰视角的童话解读

> 从 christian-film-reviews 的 `write-film-review` 移植而来，并以《海的女儿》试写一轮后修订。童话与电影最大的不同：文本短、版本多、常被改编得面目全非，而且很多童话的作者本人就在用信仰写作——所以"读准原著"和"分清哪些是作者的、哪些是解读者的"比影评更要紧。

## 输入

- **童话名**（必需）。若有歧义（如《灰姑娘》有贝洛版和格林版），默认取信仰元素更明确的版本，并在文中说明。
- **风格**（可选）：见下文四种预设，未指定时默认**文学随笔式**。
- **篇幅**（可选）：默认 2000–3000 字。短篇童话可短评（800–1200 字）。

## 五个基本要求（每篇必须全部满足）

1. **引用圣经经文。** 全篇 3–5 处，和合本，标书卷章节。经文必须是论证的转轴，删掉它论证就断了；一处贴切胜过五处装饰。

2. **指向基督与救赎，指出人心的罪。** 先诚实呈现故事揭示的人性困境（把永恒押在受造物上、自义、骄傲、惧怕、交易式的爱），再指出它在人自身之内无解，最终走到十字架与恩典。不停在道德劝勉（"要做个善良的孩子"）——这恰恰是许多 19 世纪童话自己的毛病，解读者不要重复它。

3. **挖掘文本细节。** 至少深挖 4–6 个具体细节：一句话、一个物件、一个数字、一处首尾呼应（如《海的女儿》开头花园里"红得像太阳的花"与结尾"神的太阳"）。童话短，作者的每个物件几乎都是有意放的，细读回报很高。属灵解读必须从细节里长出来。

4. **每个角色都有描述。** 主角逐一有肖像与属灵判语；配角（包括只出场一次的、非人的——锡兵、火柴、冷杉树、巫婆的房子）至少点到它在主题中的位置。童话角色常是一种人心样式的纯化版本，把这张"人心地图"画全。

5. **诚实地对照原著的神学。** 童话里的信仰元素不都等于福音。作者若写了靠行为挣得灵魂、炼狱式的试炼、把死亡浪漫化为解脱、"好孩子上天堂"式的训诫，要温和而清楚地指出它与圣经的距离（常用经文：以弗所书 2:8-9、罗马书 3:23-24）。同时去找文本里**比作者自己的结论更深**的地方——《海的女儿》的结尾说灵魂要靠三百年善行挣得，但她被接上天空，是在扔掉刀之后、做任何善行之前。既不替作者粉饰，也不居高临下地审判。

## 工作流程

### 1. 确定版本、核实原文（先于一切写作）

- **只解读原著，不解读改编。** 迪士尼、绘本缩写、教科书节选常常删掉了全部信仰内容（《海的女儿》的不朽灵魂、《灰姑娘》母亲坟上的榛树与祷告）。文中可以一句话点出改编删了什么，这本身就是论据。
- 用公有领域的英译本逐一核对情节、角色、原话，WebFetch 可达的来源：
  - 安徒生：南丹麦大学安徒生中心 Jean Hersholt 英译 `https://andersen.sdu.dk/vaerk/hersholt/<TitleNoSpaces>_e.html`（如 `TheLittleMermaid_e.html`），比维基百科摘要细得多，能逐句核对。
  - 格林：Margaret Hunt 英译（可经 WebSearch 找公开全文页）。
  - Project Gutenberg 在本环境 curl 会被代理拒绝，WebFetch 偶尔可用但常截断，不要依赖。
- **宁可省略，不可虚构。** 记不准的原话不加引号，改为转述。数字要核（《海的女儿》里善行缩短的是"一年"，眼泪延长的是"一天"——摘要网站常写错）。
- 查作者本人对这篇的说法（书信、自传、日记），能找到可靠出处才用。安徒生 1837 年谈《温蒂妮》的信就是解读《海的女儿》的钥匙。
- 列出角色清单，写作时逐一勾掉。

### 2. 判断信仰层次

动笔前先判断这篇童话属于哪一层，它决定你能对"作者意图"说多少话：

- **显性**：作者本人在用基督教世界观写作，文本里有神、教堂、祷告、灵魂、天使（安徒生大部分作品、王尔德《快乐王子》《自私的巨人》、乔治·麦克唐纳）。可以直接讨论作者的神学，也要对照它（要求 5）。
- **底色**：民间故事经基督教欧洲流传，带着信仰的残迹（格林兄弟后期版本中的祷告、坟上的树、天使）。讨论"这个故事在基督教文化里长成了什么样"，不归给某个作者的意图。
- **共鸣**：文本没有信仰元素，但它的结构与福音相合（替代、舍己、变形、死而复生、"欢乐的突转"）。必须明说"这是解读者的读法"，可借托尔金《论童话》里"善灾"（eucatastrophe）的概念。不要硬说作者是基督徒或故事是寓言。

在 front matter 的 `faithLayer` 字段记下判断。

### 3. 找到"福音枢纽"

用一句话回答：**这个故事里人心的病是什么？福音对它说什么？** 例：《海的女儿》——她把对永恒的渴望押在一个凡人的爱上，并为此付出最好的东西；而福音说，灵魂不是用交易换来的，是那位舍己者白白给的。

然后找**决断时刻**：童话的高潮几乎总是一个选择（扔不扔刀、开不开门、回不回头）。这一刻常是福音最清晰的影子，文章的重心应放在这里，而不是婚礼或大结局。

**双重预表**：同一个角色可以前半是"我们"、后半隐约像"基督"（小人鱼先是把永恒押在王子身上的罪人，后是默默救人、不被认出、受苦不开口、舍己的人）。可以这样读，但要明确说出两重身份的切换点，并承认"作者未必有意"；不要把每个王子都读成基督、每个巫婆都读成撒但。

### 4. 选定风格并写作

通用结构（不必每段打小标题；`##` 小标题可用来分节，3–6 个为宜）：

0. **标题**：首选故事里自己说出的那句"诊断"，原样或略改（如"我愿用三百年，换做人的一天"）。忌《XX》解读式流水标题，忌读完才懂的典故。
1. **开头**：从一个具体物件或画面切入，不从"这是安徒生的一篇……"开始。
2. **主题还原**：若改编遮蔽了原著，在这里把原著真正的主题立起来。
3. **人物群像**（要求 4）。
4. **决断时刻**：福音的影子在这里显现（要求 1、2）。
5. **对照**：作者的结论 vs 圣经（要求 5）。
6. **结尾**：回到开头的物件，落在盼望。

### 5. 自检清单

- [ ] 3–5 处和合本经文，有章节，都在承重？
- [ ] 有"罪的诊断"，且走到了基督与恩典，没有停在"做好孩子"？
- [ ] 4–6 个文本细节，全部经公有领域原文核对，无虚构、无从改编版混入的情节？
- [ ] 每个角色（含配角、非人角色）都有位置？
- [ ] 对原著神学的偏差有诚实对照，也找到了文本比作者结论更深的地方？
- [ ] 对作者意图的断言与 `faithLayer` 相称？"共鸣"层没有被说成作者本意？
- [ ] 标题出自故事自己的诊断句？

## 风格预设

风格改变语气、节奏、引经方式和读者对象，不改变五个基本要求。用户也可描述自定义风格，提取"读者、语气、句法、引经方式"四要素后就近参照。

**1. 文学随笔式（默认）** 读者为普通文艺读者，含非信徒。冷静克制，长短句交错，善用对仗与首尾呼应；经文像引文学经典一样自然引入，引后用文学语言消化，不布道；慎用教会行话。

**2. 牧者讲道式** 读者为信徒与慕道友，可直接用于主日学、读书会。恳切明白，可用"我们"，可设问；可停下来解一节经，用故事情节反过来照亮经文。忌文艺腔淹没信息。

**3. 神学思辨式** 读者为受过人文教育的读者、神学生。把童话当思想文本，与神学传统对话（奥古斯丁的"无序之爱"、路德的"内弯的人"、托尔金的"善灾"、刘易斯论童话），引文必须真实可查，不可杜撰。忌概念空转。

**4. 亲子共读式** 读者是给孩子读这篇童话的父母。上半篇写给父母：用平实的话讲清这篇故事的属灵意义和需要留意的地方（死亡、恐怖情节、作者的道德说教该怎么跟孩子讲）；文末附 3–5 个可以问孩子的问题（从故事细节问起，最后一题通向福音，如"小人鱼扔掉刀的时候，她在想什么？有没有一个人也为不爱他的人放弃过自己？"）。语言浅白，不吓唬孩子，不把福音讲成"乖孩子才被爱"。

## 引文与版权

- 童话原著（安徒生、格林、王尔德等）均已进入公有领域，可以引用；但**中文通行译本**（叶君健、杨武能等）仍受版权保护。引文一律据原文或公有领域英译**自译**，文末注明"引文据原著自译，经文引自和合本"。如需借用某中译本的经典译名或一两句名译，注明译者。
- 安徒生篇名用国内通行译名（《海的女儿》而非《小美人鱼》），首次出现可附原名。

## 输出格式

保存为 `reviews/<tale-id>.md`（tale-id 用通行中文译名的拼音短横线，如 `hai-de-nver`、`mai-huochai-de-xiaonvhai`）：

```markdown

tale: 海的女儿

faithLayer: 显性（一句话说明理由）
sourceText: 核对所用的原文/英译版本
style: 文学随笔式
date: YYYY-MM-DD
---

# （标题）

（正文……）

---

*本文引文据……自译，经文引自和合本。*
```

只用 Markdown 子集：段落、`##` 小标题、`>` 引用、粗体/斜体。不用表格和列表，以便日后渲染到网站或编书。

## 质量红线

- **贴标签式引经**：删掉经文论证毫发无损。
- **复述梗概**：按顺序把故事讲一遍。童话读者大多知道情节，细节要为论点服务。
- **道德说教腔**："我们应当做个善良的孩子"——这正是要求 5 要对照的东西，不要自己犯。
- **硬套寓言**：把每个人物都配一个圣经对应物（王子=基督、巫婆=撒但、海=世界），像填字游戏。只在文本支撑的地方做预表，并说明是解读。
- **属灵套话**：放在任何童话后面都成立的段落。诊断必须是**这篇**童话的诊断。
- **审判作者**：指出作者神学的偏差时带着敬意与"我们也在其中"的诚实，不嘲笑 19 世纪的虔诚。
- **混入改编**：迪士尼的乌苏拉、灰姑娘的南瓜马车神仙教母（贝洛版）混进格林版解读。
- **虚构细节或引文**：原话、数字、作者书信都要有出处。

## 候选篇目（待解读，动笔前仍须逐一核对原文）

- 安徒生：《卖火柴的小女孩》（死亡与祖母的怀抱——需对照"死亡即解脱"的浪漫化）、《冰雪女王》（格尔达唱的赞美诗，"玫瑰花开在山谷里，在那里能见到圣婴"）、《野天鹅》（艾丽莎在墓地采荨麻、长久的沉默与受冤）、《红鞋》（卡伦、教堂、天使与悔改）、《踩着面包走的女孩》（骄傲与堕落）、《丑小鸭》（共鸣层：身份是被赐予的还是挣来的）、《坚定的锡兵》、《枞树》（永远等待"下一个更好的时刻"）。
- 王尔德：《自私的巨人》（显性：孩子手脚上的伤痕——"这是爱的伤痕"）、《快乐王子》（舍己与神选中"城里最珍贵的两样东西"）。
- 格林：《灰姑娘》（母亲遗言"要虔诚善良"、坟上的榛树与白鸽）、《汉赛尔与格莱特》（"神不会丢弃我们"）、《无手少女》。
- 乔治·麦克唐纳：《公主与妖精》（看不见的线与看不见的祖母——信心）。
